# Briefing: perguntas e checklist

Pergunte só o que o pedido não responde, de uma vez, com opções. Feche tudo antes de construir.

## Perguntas (com padrões quando o usuário não quiser decidir)

| Item | Opções / padrão |
|---|---|
| Uso | estudo interno (padrão) · portfólio · campanha real (aí exigir assets oficiais e licenças) |
| Duração / formato | 15 s · **30 s** · 45 s — **16:9 1920×1080** · 9:16 (girar layout) |
| Conceito | tour pelo app com clima de marca (padrão) · demo de funcionalidade · lançamento de recurso |
| Funcionalidades | 3–5 momentos no máximo para 30 s, por exemplo:<br>• abrir o app<br>• buscar/digitar<br>• resultado<br>• recurso de IA<br>• estatística/resumo<br>• fechamento |
| Dispositivo | iPhone iOS 26 (único modelo 3D disponível) |
| Áudio | música + SFX (padrão) · + narração (Kokoro TTS pt-BR, se instalado) |
| Música | real e livre (NCS/SoundCloud) com drop · trilha sintetizada · arquivo do usuário |
| Idioma da UI | pt-BR (padrão) |
| Slogan / CTA | do usuário ou proposto (curto, 3–5 palavras, entra palavra por palavra na batida) |
| Visual | paleta da marca + fundo escuro (padrão) · claro |
| Conteúdo da UI | fictício (padrão): nomes, capas, números inventados e coerentes |
| Prints do app | pedir 4–6 prints das telas que vão aparecer (melhor fidelidade) |

## Checklist de assets
- [ ] Logo oficial em SVG baixado da página de marca. Anotar as regras: cor única, área de respiro, fundos permitidos.
- [ ] Cores oficiais e as cores medidas nos prints: fundo, cartões, texto secundário, destaque.
- [ ] Fonte: se for proprietária, usar uma substituta próxima com arquivo local. Figtree já vem no template.
- [ ] Imagens fictícias (capas, fotos, produtos) geradas e revisadas: sem texto ilegível, sem marcas reais.
- [ ] Música cortada com o drop no ponto planejado e o crédito anotado.
- [ ] Privacidade: nada de nome, foto ou conteúdo pessoal dos prints do usuário.

## Estrutura de roteiro que funcionou (30 s, drop em 10 s)

| Tempo | Cena |
|---|---|
| 0–2,6 | Gancho: celular 3D em 3/4, luz varrendo, pergunta na tela em palavras. |
| 2,6–5 | Mergulho na tela até os ícones, e o app anunciado ganha destaque. |
| 5–6,3 | Toque + animação de abertura do app; a câmera recua para o celular inteiro. |
| 6,3–10 | Função 1 com digitação em close seguindo o cursor; resultados entram na batida; toque. Contração para um ponto. |
| 10 | Drop: clarão, cor da marca/capa inunda o fundo, órbita do celular, texto grande no ritmo. |
| 13,7–17,4 | Função 2 (por exemplo IA): card de vidro grande ao lado do celular espelha o que é digitado; faíscas; resultado montando item a item. |
| 17,4–24,9 | Mundo da marca em tela cheia: cards de vidro com números, um por compasso, transições em chicote. |
| 24,9–28,6 | Elemento gráfico vira o ícone da marca; slogan palavra por palavra na batida. |
| 28,6–30 | Logo oficial completo + linha pequena "Peça conceitual — estudo" + crédito da música. |
